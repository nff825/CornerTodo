# CornerTodo macOS 0.1.0-alpha.1 · 内测清单

本包由 Windows 交叉构建，Mac 真机尚待验收，无 Developer ID 发布者签名和 Apple 公证。目标 macOS 14+，按芯片选择 ARM64 或 Intel x64。普通测试者无需安装开发环境。

## 三分钟启动检查

- [ ] 完整解压后，双击 CornerTodo.app 是否能正常启动？如有系统提示，请截图。
- [ ] 桌面右上角是否出现面板，文字、背景和按钮是否清楚？
- [ ] 菜单栏是否有入口，能否恢复面板和退出？外观设置可从面板的「⋯」菜单打开。
- [ ] 添加一个测试事项，设置截止时间，保存后是否显示？
- [ ] 完成该事项，能否在已完成区域看到划线记录并恢复？
- [ ] 退出再打开，测试事项与设置是否保留？

若启动受阻，先确认来源，再参考 [Apple 官方说明](https://support.apple.com/en-us/102445)。若提示已损坏、会损坏电脑或立即退出，请反馈截图、系统版本与芯片；不需要关闭系统安全保护或执行重新签名、清除隔离属性等脚本。

## 任务、时间与草稿

- [ ] 新增与编辑内容、备注、优先级均可保存；取消不保存本次修改。
- [ ] 截止日期可选择；具体时刻可分别选择小时、分钟，并可键盘输入任意分钟，如17:23。
- [ ] 00:00与23:59有效；非法输入有提示且草稿仍保留。
- [ ] 不设置具体时刻时，当天结束前不算逾期。
- [ ] 只修改正文、备注、优先级或排序，不重置时间进度起点。
- [ ] 截止时间优先与优先级优先排序可切换；重新打开后选择仍保留。
- [ ] 删除前有确认，取消不删除；只使用合成测试事项进行删除测试。
- [ ] 时间细条表达已用时间，不代表完成比例；完成后隐藏，恢复后按当前时间显示。

## 贴边收起与面板尺寸

- [ ] 首次运行，贴边自动收起默认关闭。
- [ ] 从菜单开启后，拖到主屏右侧；鼠标离开约0.8秒后缩成胶囊。
- [ ] 胶囊显示未完成总数及其中逾期数，悬停不自动展开，点击可展开。
- [ ] 刚点击展开或恢复位置时，面板不会立刻再次消失；实际移入使用后再离开可收起。
- [ ] 编辑任务或菜单打开期间，面板不自动收起、操作目标不移动。
- [ ] 拖离边缘可取消贴边；关闭开关可恢复正常面板。
- [ ] 有临期或逾期事项时，面板展开后的尺寸、字号与提示符合紧急程度；收起时不因到期反复弹出。
- [ ] 退出、重新打开、关闭贴边后，常态大小未被胶囊的小尺寸覆盖。
- [ ] 菜单栏恢复入口能在面板找不到时将它移回可见位置。

## 外观与 Mac 桌面行为

- [ ] 浅色、深色与自定义颜色可保存；取消预览后恢复原外观。
- [ ] 调高背景透明度时，文字仍清楚，胶囊和菜单入口仍可找到。
- [ ] 打开其他应用后，面板可被遮住，不应一直覆盖在工作窗口上。
- [ ] 切换 Spaces、Mission Control、Stage Manager 或其他应用全屏后，记录面板实际出现的位置；退出全屏后应可恢复。
- [ ] Retina缩放、外接屏、拔除显示器后，面板不应永远留在屏幕之外。
- [ ] 休眠唤醒后，截止信息与时间进度按当前时间更新。
- [ ] 正在其他软件输入时，面板刷新不应抢走键盘焦点。
- [ ] 退出后，面板、胶囊与菜单栏入口一并结束，不再弹出。

本清单中的 Mac 平台项目尚未全部验证，请如实记录结果，不必为覆盖全部场景改变日常环境。
