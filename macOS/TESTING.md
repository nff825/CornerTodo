# CornerTodo macOS v0.2.0-alpha.1 · 内测清单

构建号 **0.2.1**。目标 macOS 14+，Apple M 系列选择 arm64，Intel 选择 x64。普通测试者无需开发环境。此包由 Windows 交叉构建，Mac 原生行为尚待验收，没有 Developer ID 签名／Apple 公证。

请先备份已有 CornerTodo 数据，只用示例事项测试；先完成以下三分钟检查，再按条件继续。不必改变日常环境以覆盖所有组合。

## 三分钟检查

- [ ] 下载后完整解压，双击 CornerTodo.app：能否启动？若有系统提示请截图。
- [ ] 右上角面板和菜单栏入口是否可见？「关于 CornerTodo」是否显示 0.2.0-alpha.1／0.2.1？
- [ ] 新增有日期和无日期事项：保存、编辑、取消、完成、恢复是否正常？
- [ ] 从菜单退出再打开：事项、优先级、备注和设置是否保留？
- [ ] 用菜单栏「显示待办／恢复右上角位置」找回面板，再退出：入口与窗口是否一起结束？

首次运行提示可参考 [Apple 官方说明](https://support.apple.com/en-us/102445)。若提示损坏、会损坏电脑或启动即退，请反馈原文与设备信息；不需要关闭系统防护或执行处理隔离属性、签名的脚本。

## 新功能与升级

- [ ] 取消「设置截止日期」后相关控件收起，可以保存「未设截止」事项。
- [ ] 无日期事项不显示时间条，不计入逾期／6小时内数量，不驱动面板扩大。
- [ ] 浅色、深色、自定义颜色和高透明背景下，顶部按钮、添加按钮及滚动条清楚；悬停／按下不丢底色。
- [ ] 长列表支持滚轮、拖动细滑块，文字不被遮挡。
- [ ] 旧数据升级前出现独立备份，提示的 UpgradeBackups 目录可找到；个人测试后不要直接用旧版打开新数据。
- [ ] 如导入带重复／提醒／Windows悬浮配置的测试副本，程序说明当前Mac不执行这些功能，保存其他内容不会清除原配置。

## 基础回归

- [ ] 截止小时／分钟点选和输入任意分钟，如17:23；无效输入保留草稿并提示。
- [ ] 只修改正文、备注、优先级，不重置时间进度；日期或时刻确实改变才重新计算。
- [ ] 已完成保留划线，恢复后日期与备注保留；两种排序选择重开后保留。
- [ ] 默认不贴边收起；开启后主屏右侧离开约0.8秒收起，点击胶囊展开。
- [ ] 编辑／菜单打开时保持展开；胶囊尺寸不覆盖常态尺寸。
- [ ] 菜单栏恢复或双击启动不会重复创建多个独立程序。

## Mac 平台检查

- [ ] 切换其他应用时面板能被遮住，刷新不抢走正在输入的焦点。
- [ ] 切换 Spaces／Mission Control／全屏，再退出全屏，面板能找回。
- [ ] Retina缩放、外接屏或拔掉显示器后，面板不会永久留在屏幕外。
- [ ] 休眠唤醒后时间信息更新，菜单栏和编辑窗口仍可操作。
- [ ] Command+Q、菜单退出、编辑期间退出的结果明确，未保存草稿不会被静默丢弃。
