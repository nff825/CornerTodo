# CornerTodo macOS v0.2.0-alpha.1

构建号 **0.2.1**，目标 **macOS 14+**，提供Apple芯片arm64／Intel x64两种自包含包。本版为实验性内测，尚待Mac真机验收，没有Developer ID签名或Apple公证。

## 本轮更新

- 截止日期可选：取消「设置截止日期」即可保存「未设截止」事项，日期／时刻控件按需展开。
- 统一顶部操作区和添加按钮的底色、圆角与交互反馈，适配浅色、深色、自定义配色和高透明背景。
- 主列表采用透明轨道与圆角细滑块，保留足够的拖动范围；胶囊保持可辨认底色。
- 增加迁移前独立备份，旧数据升级到当前Version4前保留可回退的副本。
- 增加关于与反馈信息，显示版本、构建号及环境信息；恢复面板与退出入口继续保留。
- 保留完成／恢复、备注、优先级、排序、时刻点选、外观、尺寸增长及默认关闭的右侧贴边收起。

## 功能范围

本版未接入Mac重复任务设置／生成／管理、提醒调度／卡片或悬浮模式。导入Windows配置时保留相关数据并说明范围，不代表Mac会执行其计划。手机端、自动同步与Mac登录自启不在本轮范围内。

## 下载

M1等Apple M系列Mac下载 `CornerTodo-macos-v0.2.0-alpha.1-arm64-experimental.zip`；Intel下载x64包。完整解压后双击CornerTodo.app，普通用户无需安装开发环境。源码ZIP供维护者阅读与构建。

## 升级与测试

先退出旧程序并另存备份 `~/Library/Application Support/CornerTodo/`。本版迁移前自动备份放在该目录的 `UpgradeBackups` 下；备份失败停止升级。原alpha.1无法读取Version4，回退先恢复旧数据。

先按TESTING.md检查启动、保存／重开、菜单栏恢复与退出，再记录Spaces、全屏、缩放、多屏和休眠结果。请用FEEDBACK.txt反馈，不发送个人待办文件。Windows辅助界面与静态打包检查不等于Mac真机验收。
