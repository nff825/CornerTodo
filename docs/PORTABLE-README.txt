CornerTodo 角落待办 v1.8.0

本次新增默认关闭的到期提醒：勾选后才展开天/小时/分钟，组合一次提前时长，全0到期提醒。现有悬浮、重复任务、无截止日期、外观和登录自启继续保留。

使用方法
1. 将整个压缩包解压到一个你有写入权限的固定文件夹。
2. 双击 CornerTodo.exe。请保留同目录的 CornerTodo.exe.config。
3. 点击“添加待办”，输入事项；需要日期时勾选“设置截止日期”，不需要时取消。具体时刻可选，小时00–23和分钟00–59分别点选，也可键盘输入；优先级默认“中”。
4. 需要补充信息时展开“备注（选填）”，输入多行文字；新建时默认收起，编辑已有备注时自动展开。
5. 点击事项旁圆圈切换完成状态；双击或右键事项进行编辑。列表上的备注图标可直接进入备注，完成后仍保留。
6. 可选择“截止时间优先”或“优先级优先”排序，程序记住你的选择。
7. 拖动标题移动面板。菜单可折叠、关闭自动扩大和退出。
8. 需要时从“⋯”菜单开启“贴边自动收起”，将面板贴到主屏右侧；鼠标离开约0.8秒后缩成胶囊，点击可展开。
9. 需要在其他软件上方查看时，从“⋯→显示方式”选择“悬浮在其他窗口上方”；选择会保存，默认仍为“仅在桌面显示”。

到期提醒
先设置截止日期和具体时刻。默认只显示未勾选的“提醒我”，勾选才展开设置。
提前天数0–3650、小时0–23、分钟0–59，支持点选和输入；全0表示到期提醒。下方显示准确日期，保存才生效。
取消日期/具体时刻会关闭提醒。新建或修改后的提醒时间已过时不突然补弹。
程序运行期间独立检查，面板收起或被其他软件遮挡时也可提示；多项合并一张卡片。
卡片可查看事项、标记完成，右上角关闭只收起提示；主面板不会强制展开。
处理状态本地保存，重启不重复。完成、删除、关闭提醒或改计划后撤下旧卡，仅改文字不重置。
重开或休眠恢复后只合并最近24小时有效遗漏；本应用编辑/菜单/模态期间暂缓展示。
重复规则的提醒可能在日历生成日前提前创建对应事项，保存期次标记后删除或重启也不重生。
修改后续/暂停/停止保留已生成事项，含已提前生成的事项；历史补建不逐项弹窗。
需要保持程序运行；退出、关机或睡眠期间不检查，不唤醒电脑，无声音或系统后台通知。

显示方式与统一外观
桌面模式可被其他软件覆盖；悬浮模式下，面板和贴边胶囊可显示在浏览器、文档编辑器等普通窗口上方。
桌面与悬浮分别保存“随截止时间扩大”开关。桌面保留原偏好；悬浮默认不自动扩大，先使用常态尺寸，可自行开启。
切换不改变事项，保留常态位置与尺寸。全屏、其他置顶窗口和系统安全界面的层级以实际环境为准。
顶部操作区与“添加待办”使用同系底色、圆角、描边和悬停/按下反馈，跟随浅色、深色及自定义外观。
滚动条保留透明轨道、细圆角滑块和足够的拖动区域。

重复任务
默认只有一行未勾选的“重复任务”。勾选后才显示重复方式与开始日期。
每日生成一次；每周选择一个或多个星期；每月选几号或最后一天。短月采用月底，下月恢复原定几号。
重复计划和截止日期独立，无截止事项也可重复；有截止时每期按首期相对开始日期的间隔计算。
每一期独立保留，完成时间不改变计划。右键可编辑本次或修改后续，停止和暂停不会删除已有事项。
“⋯→管理重复任务”查看未来规则与下次日期，可暂停、恢复或停止。
程序运行/重新打开时检查生成。漏期先汇总，让你选补建、跳过或稍后；每批最多366项。
暂停或修改前先处理既有遗漏；恢复不追补暂停期间。停止后尚未生成的遗漏周期也不再补建。
未来开始的规则可能暂时不出现在清单，可在管理窗口查看。
可选提醒需程序保持运行，退出或关机时也不运行生成。

时刻点选
勾选“设置具体时刻”后，分别选择小时和分钟，支持任意分钟，如17:23；无需手动输入冒号。
取消勾选后只保存截止日期。编辑时带出原时刻，日期和时刻未变不会重置时间进度。
输入不合法或保存失败时保留输入，可修改后重试。

贴边自动收起
默认关闭，选择保存在本地。首版支持主屏右侧，开启后靠近边缘可吸附，拖离边缘可继续普通面板使用。
贴边后鼠标真正离开约800毫秒才收起；点击胶囊展开，仅悬停不会展开。
编辑、打开菜单或拖动时保持展开，收起期间不会因为到期或逾期反复弹出。
胶囊显示未完成总数和其中的逾期数，例如未完成3、逾期1表示三项中一项逾期。
展开后按当前紧急程度恢复尺寸，临时胶囊尺寸不覆盖常态大小；原有标题栏手动收起独立保留。
菜单“恢复右上角位置”或再次双击同一份CornerTodo.exe可找回并展开面板，直到鼠标下一次离开后再自动收起。
桌面模式下胶囊和面板可被其他软件覆盖，悬浮模式下保持在普通窗口上方。关闭贴边自动收起后恢复普通面板。

无截止日期与简约滚动条
新建默认勾选“设置截止日期”，取消后收起日期及具体时刻，编辑无日期事项时保持关闭。
无日期显示“未设截止”，不显示时间条，不计入临期或逾期，不推动面板扩大；仍计入未完成总数。
截止时间优先：有日期在前，无日期按创建时间在后。优先级优先：先分高/中/低，同级内有日期在前。
为无日期事项补设日期，从本次保存计算进度；取消截止后按剩余事项重新计算面板紧迫度。
主面板滚动条采用透明轨道和细滑块，悬停/拖动加深，保留固定宽度的操作范围。

备注、优先级与时间条
备注只保存在本机，不展开占用桌面列表；取消编辑不会保存本次输入。
优先级默认为“中”。默认按截止时间排序；选择优先级优先时，高→中→低，同级内按截止时间排序。
优先级优先不会额外强制逾期置顶，较晚截止的高优先级事项可能排在较早截止的中优先级事项前面。
有截止日期的未完成事项下方的细条约3像素，表示时间已用比例，鼠标悬停可查看百分比，不表示工作完成度。
创建或重新设定有效截止时间时为起点，到截止时满格；逾期保持满格并显示逾期时长，已完成事项隐藏时间条。
三天、五天、一个月的事项分别按自己的完整周期线性推进。
仅修改文字、备注、优先级或排序，以及关闭后重新打开程序，都不会重置进度。
恢复未完成后，按原起点与当前时间重新显示进度。

开机自启（登录后）
默认关闭，首次运行和升级不会自动开启。需要时，从“⋯”菜单自行点击“开机自启（登录后）”。
开启仅在当前Windows用户启动文件夹登记CornerTodo-LoginStartup.lnk；关闭只删除本工具管理的快捷方式。
菜单勾选代表快捷方式已登记；Windows若外部禁用了该项，仍需你在系统设置中重新启用。
程序不会在后台覆盖、重建或重新启用Windows已禁用的启动项，也不在JSON保存跨机器启用开关。
退出只结束本次运行；下次登录按登记启动。自动重复启动会静默退出，不展开或重置已有面板。
原目录升级保留已有登记。移动目录后，手动打开新位置程序，再点击“更新自启位置为当前程序”。
删除软件前，请先关闭登录自启动，避免留下失效快捷方式。

外观设置
从“⋯”菜单打开“外观设置”。背景透明度0%为实色，100%为全透明，文字不会随背景一起变淡。
支持背景色、主要文字色和次要文字色；可选浅色、深色与恢复原版预设。
调整时实时预览，点击保存后生效；取消或关闭窗口恢复已保存设置。
背景全透明时顶部操作区与“添加待办”仍可辨认；配色看不清时，可从菜单选择“恢复清晰浅色”。
旧版数据自动保留原版外观，修改主题不会改变事项和保存的常态尺寸。

截止时间与面板
时间条使用完整周期；面板自动扩大继续单独按临期规则计算。
最后24小时逐渐扩大；不足24小时的任务按自身可用时间计算。
面板展开且当前模式开启自动扩大时，只要有逾期未完成事项，就持续保持最大面板。
贴边胶囊状态优先于自动扩大，收起后不会被截止变化强制展开。
最大宽度为工作区的一半，高度约72%，以2560×1528工作区为例约1280×1100。
所有6小时内和逾期未完成事项均放大字号；鼠标操作和编辑期间暂停尺寸变化。
仅设置日期的事项在次日零点才逾期。

数据与升级
首次运行后，程序旁会生成 Data 文件夹，里面保存个人事项、备注、优先级、排序、外观、贴边偏好和备份。
移动程序时请连同 Data 一起移动。公开分享程序时不要包含自己的 Data 文件夹。
升级前先从菜单退出旧版并备份整个 Data，再替换程序文件，保留原 Data。
v1.3.0数据缺少贴边设置时按关闭读取，原有事项和设置继续保留。
更早的v1.2.1数据缺少备注等字段时按空备注、中优先级、截止时间优先读取。
本版保存为Version 4，保留提醒计划/处理状态和提前生成期次。
旧Version 1/2/3载入只在内存迁移，旧事项默认关闭提醒，首次成功保存才写新版。
v1.7.0及更早Windows程序与已发布Mac 0.1.0-alpha.1不能读取Version 4。
回退前先恢复单独保存的升级前整个Data备份，再运行旧版；不能只依赖滚动更新的todos.json.bak。
不要让新旧版交替写入同一份数据。
登录自启动的Windows快捷方式与Data分开保存，移动目录后需手动更新登记。
请不要在压缩包预览窗口中直接运行，也不要放在没有写入权限的目录。

系统环境与范围
面向 Windows 10 / 11，使用 .NET Framework 4.7.2 或更新版本。
默认桌面模式可被其他软件覆盖；悬浮和登录自启动均由用户自行开启。程序不联网。
本便携包仅为Windows程序；Mac内测单独分发。当前没有手机端、跨设备同步、声音/系统后台通知、附件、富文本或子任务。
不同 Windows 版本、显示缩放与多显示器环境尚未全部验证，真实登录和Explorer重启等场景仍需实机检查。
