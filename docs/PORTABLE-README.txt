CornerTodo 角落待办 v1.0.0

使用方法
1. 将整个压缩包解压到一个你有写入权限的固定文件夹。
2. 双击 CornerTodo.exe。请保留同目录的 CornerTodo.exe.config。
3. 点击“添加待办”，输入事项，选择截止日期及可选的具体时刻。
4. 点击事项旁的圆圈切换完成状态；双击或右键事项进行编辑。
5. 拖动标题移动面板。菜单可折叠、关闭自动扩大和退出。

系统环境
面向 Windows 10 / 11，使用 .NET Framework 4.7.2 或更新版本。
其他软件可以覆盖面板；不联网，不设置开机自启动。
不同 Windows 版本、显示缩放与多显示器环境尚未全部验证。

截止时间与面板
最后24小时逐渐扩大；不足24小时的任务按自身可用时间计算。
只要有逾期未完成事项，就持续保持最大面板。
最大宽度为工作区的一半，高度约72%，以2560×1528工作区为例约1280×1100。
所有6小时内和逾期未完成事项均放大字号；鼠标操作和编辑期间暂停尺寸变化。
仅设置日期的事项在次日零点才逾期。

数据与升级
首次运行后，程序旁会生成 Data 文件夹，里面保存个人事项和备份。
移动程序时请连同 Data 一起移动。公开分享程序时不要包含自己的 Data 文件夹。
升级前先从菜单退出旧版并备份 Data，再替换程序文件，保留原 Data。
请不要在压缩包预览窗口中直接运行，也不要放在没有写入权限的目录。

Windows 信任提示
本版本没有发布者数字签名。部分 Windows 安全策略可能提示或阻止运行。
请先核对下载来源及随发布提供的 SHA256 校验值，再按自己的设备策略处理。
如设备策略阻止运行，可以审查并自行构建源码；自行构建也不保证被策略允许。
