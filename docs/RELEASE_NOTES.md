# CornerTodo v1.12.0｜关联原文件

为事项关联多个原文件，在桌面清单、截止日历和四象限中快速打开、定位或重新关联。文件继续保存在原来的位置，CornerTodo 只记录绝对路径。

- 添加或编辑时选择一个或多个原文件；取消编辑不保存本次增删。已有记录显示小回形针和数量，点击查看文件列表。
- 支持打开文件、打开所在位置、重新关联与移除关联。文件移动、改名或暂时不可访问时保留原路径，可重选原文件。
- 移除关联、完成或删除事项不会删除、移动或复制原件。关联增删保存失败时不提交，不改变截止计时、提醒计划或其他任务字段。
- 重复规则可保存关联，未来每一期继承同一原文件路径；编辑本次不改变规则或其他期次，修改后续保留已生成事项的关联。

文字大小、四象限、截止日历和到期提醒继续提供，历史变更见 `CHANGELOG.md`。Mac 已分发版仍为 0.2.0-alpha.1（构建 0.2.1），使用 Version 4 数据；本次仅同步开发源码的字段保留，没有新 Mac 关联界面或程序。

## 下载与升级

Windows 便携包为 `CornerTodo-v1.12.0-windows-portable.zip`，完整解压后运行 `CornerTodo.exe`。源码包为 `CornerTodo-v1.12.0-source.zip`，校验文件为 `SHA256SUMS.txt`。

升级前从菜单退出旧程序，**另外复制并保留整个 `Data` 文件夹**，再替换程序文件、保留原数据。换目录运行时带上原 `Data`；移动目录后手动更新已登记的自启位置。

本版使用 **Version 6** 数据格式。Version 1～5 正常载入时只在内存迁移，缺少关联字段时为空列表，首次成功保存后写入 Version 6。原有日期、重要标记、备注、提醒、周期与显示偏好继续保留。

**Windows v1.11.0 及更早版本和已分发的 Mac 内测程序无法读取 Version 6。回退时先恢复升级前另存的整个 `Data`，再启动旧版。** 日常 `todos.json.bak` 会滚动更新，不能替代这份独立备份。

**`Data` 与其备份只包含原文件路径，不包含原文件。** 请另行保管原件；移动原件或换电脑后需重新关联。本次不提供附件上传、文件打包或自动同步。

## 系统要求与验证

系统目标为 Windows 10／11 和 .NET Framework 4.7.2 或更新版本。自动检查结果以同批 `PACKAGE-REPORT.txt` 为准。实际系统文件选择、外部程序打开、资源管理器定位、窗口焦点、多屏与缩放仍需在目标设备检查，实际控件离屏渲染仅证明布局。

便携程序未进行发布者数字签名。可用 SHA256 核对文件一致性。许可证为 MIT，见 `LICENSE`。本地准备发布文件不会自动上传或创建 GitHub Release。
