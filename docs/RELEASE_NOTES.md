# CornerTodo v1.4.0

本次改善具体时刻输入，并增加默认关闭的贴边收起：小时、分钟可以分别点选；面板贴到主屏右侧后，鼠标离开片刻会缩成胶囊条，点击即可展开。

- **时刻点选**：小时 00–23、分钟 00–59 分别选择，也支持键盘输入。可选择任意分钟；不勾选具体时刻时仍只设置日期。
- **可选贴边收起**：从“⋯”菜单开启，默认关闭，选择会保存在本机。首版支持主屏右侧，靠近右边缘可吸附；鼠标真正离开约 800 毫秒后收起，点击胶囊展开，仅悬停不展开。
- **胶囊保留任务提示**：显示未完成总数及其中的逾期数量，任务数据和列表排序不因收起改变。
- **操作期间保持展开**：编辑任务、打开菜单、拖动时不自动收起。收起期间不会因到期或逾期自动弹出，展开后按当前紧急程度恢复面板尺寸。
- **保留恢复入口**：菜单“恢复右上角位置”或再次手动启动同一份程序可找回面板，保持展开直到鼠标下一次离开。临时胶囊尺寸不覆盖常态大小，原有标题栏手动收起独立保留。
- **旧数据与时间精度**：旧版事项继续读取，缺少贴边设置时默认关闭。日期与时刻未变时保留原始截止精度，不重置进度；校验或保存失败仍保留输入供重试。

备注、高／中／低优先级、两种排序、约 3 像素的时间进度细条、外观设置和本地备份继续保留。时间条表示经过的时间，不表示工作完成度；只有有效截止时间变化才重设进度起点。优先级优先按高 → 中 → 低、同级按截止时间排列，不额外强制逾期置顶。

面板和胶囊仍只在桌面层显示，其他软件可以覆盖它们。登录自启动仍默认关闭，由用户自行开启。应用面向 Windows 10 / 11，需要 .NET Framework 4.7.2 或更新版本；本地保存、不联网。当前不包含 Mac／手机端、跨设备同步、提醒通知、附件、富文本或子任务。

## 下载与升级

- 使用程序：下载 `CornerTodo-v1.4.0-windows-portable.zip`，完整解压后运行 `CornerTodo.exe`。
- 查看或构建源码：使用仓库代码，或下载 `CornerTodo-v1.4.0-source.zip`。
- 校验文件：`SHA256SUMS.txt`。

升级前先从菜单退出旧版并备份程序旁的整个 `Data` 文件夹，替换程序时保留原数据目录。长期使用建议固定同一个运行位置；每份便携程序默认读取自己旁边的 `Data`，切换到新的版本目录不会自动带入旧事项。v1.3.0 数据缺少贴边设置时自动按关闭读取；更早的 v1.2.1 数据缺少备注等字段时，仍按空备注、中优先级和截止时间优先读取。

旧版程序写回新版数据时，会丢弃其不认识的字段，包括贴边偏好。如需回退，请使用升级前的 `Data` 备份，避免新旧版本交替写入同一份数据。

在原目录升级并保持程序路径时，已有自启登记保留。移动目录后，请手动打开新位置的程序，再选择“更新自启位置为当前程序”。删除软件前请先关闭登录自启动。完整说明见 [登录自启动说明](STARTUP.md)。
