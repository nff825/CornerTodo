# CornerTodo v1.8.0｜按需到期提醒

提醒默认关闭，勾选「提醒我」后才展开天／小时／分钟。三者组合成一次提前时长，全部为0表示到期提醒；数字可点选或输入，并实时预览准确提醒日期。

- **按需配置**：需设置截止日期和具体时刻。天数0–3650，小时0–23，分钟0–59；初次开启草稿为提前15分钟，保存才生效。
- **清晰卡片**：在程序运行期间检查，面板收起或被其他软件遮挡时也可提示。卡片独立于桌面／悬浮模式，提供查看事项、标记完成；右上角关闭仅收起提示。
- **多项合并**：同一张卡片集中展示同时到点的事项；自己的编辑器、菜单或模态窗口打开时暂缓展示，普通面板悬停不阻塞提醒。
- **计划与去重**：处理状态持久保存，重启或窗口恢复不会反复提示。仅改文字、备注、优先级不重置计划；改期、改提前时长或关闭提醒后撤下旧卡片。完成与删除取消待提醒。
- **遗漏处理**：程序重开或休眠恢复后，只合并处理最近24小时内的有效遗漏，较早记录跳过。新建或修改后的提醒时间已经过去时不突然补弹。
- **重复事项继承**：每期单独保存提醒。需要跨日提前提醒时，在触发时间提前生成对应事项，并保存期次标记；后来到生成日期或删除该事项后不会重复生成。修改后续、暂停或停止均保留已生成事项，包含已提前生成的事项。

重复任务、无截止日期、优先级、备注、视觉设置、悬浮置顶、贴边收起和默认关闭的登录自启继续保留。

## 下载与升级

Windows 用户下载 `CornerTodo-v1.8.0-windows-portable.zip`，完整解压后运行 `CornerTodo.exe`。源码包为 `CornerTodo-v1.8.0-source.zip`，校验文件为 `SHA256SUMS.txt`。

升级前从菜单退出旧程序，单独复制并保留整个 `Data` 文件夹，再替换程序文件、保留原数据。换目录运行时需带上原 `Data`；移动目录后需手动更新已登记的自启位置。

**本版首次成功保存后使用 Version 4。** 旧 Version 1／2／3 载入时只在内存迁移，旧事项默认关闭提醒，原有任务、周期与显示偏好保留。

**v1.7.0及更早Windows程序、已发布Mac 0.1.0-alpha.1不能读取Version 4。回退时必须先恢复升级前另存的整个Data备份，再运行旧程序。** 滚动更新的 `todos.json.bak` 不能替代升级前备份，不让新旧程序交替写同一目录。

## 提醒范围与验证

提醒需要保持 CornerTodo 运行；退出、关机或睡眠期间不检查，不会唤醒电脑。没有声音、系统后台通知或手机同步；可配合现有登录自启使用，但不会自动替用户开启。

处理记录在展示前保存，用于避免重启重复；卡片显示失败时在当前进程中保留并重试。异常退出恰好发生在保存与展示之间时可能错过该卡片。

自动检查覆盖时长计算、数据迁移、事务失败、去重、重复提前生成、编辑展开、卡片布局、调度与退出清理。README图片为合成数据的实际WPF离屏渲染；真实窗口显示、非激活焦点、不同显示环境与休眠恢复仍需实机检查，具体测试结果见随包 `PACKAGE-REPORT.txt`。

Mac本轮仅保持共享Version 4数据与构建兼容，没有接入Mac提醒卡片／调度、周期生成或悬浮模式，也没有发布新的Mac程序。原alpha.1附件保持原样。

Windows目标：Windows10／11，.NET Framework4.7.2或更新版本。本版未进行发布者数字签名，SHA256用于核对文件一致性。MIT，见LICENSE。
