# CornerTodo v1.6.0｜每日、每周与每月重复任务

普通事项保持简洁：重复任务默认关闭，勾选后才展开设置。本版先解决周期生成与历史保留，不包含到点弹窗或声音提醒。

- **按需开启**：选择每日、每周指定星期（可多选）、每月几号或最后一天，再设置开始日期。取消勾选会收起配置，保存才生效。
- **周期与截止独立**：无截止日期的事项也可以重复；有截止时，按首期相对开始日期的天数间隔和具体时刻计算每一期。
- **历史独立保留**：每期保存自己的完成状态、备注和周期标签，上一期未完成不覆盖，也不阻止下一期。完成晚了不改变后续计划。
- **本次与后续分开**：编辑本次只改当前事项；修改后续规则只影响后续。暂停／恢复或停止重复，已有事项和完成记录保留。
- **管理入口**：「⋯ → 管理重复任务」可查看下次生成日期、编辑规则、暂停／恢复和停止。未来开始的规则可在此查看。
- **漏期先确认**：程序运行／重新打开时检查计划。遗漏周期汇总后选择补建、跳过或稍后，每批最多补建366项，剩余继续待处理。
- **短月处理**：选择每月29／30／31日时，短月使用当月最后一天，下月恢复原定日期；也支持单独的每月最后一天。

暂停或修改规则前，需要先处理该规则已经存在的漏期。恢复从当前计划继续，不追补暂停期间；停止后，尚未生成的遗漏周期也不再补建。删除本次或重新启动不会重复生成同一期。

无截止日期、简约滚动条、备注／优先级／排序、外观设置、可选贴边收起和登录自启继续保留。

## 下载与升级

- 普通 Windows 用户：`CornerTodo-v1.6.0-windows-portable.zip`，完整解压后运行 `CornerTodo.exe`。
- 源码：`CornerTodo-v1.6.0-source.zip`，包含 Windows 工程及保持共享数据兼容的 Mac 开发工程。
- 摘要：`SHA256SUMS.txt`。

升级前先退出旧程序，单独复制并保留整个 `Data` 文件夹，再替换程序文件、保留原数据。固定日常目录可保留已有登录自启登记；移动目录后需手动更新自启位置。

**本版保存为 Version 3。** 旧 v1/v2 载入只在内存迁移，首次成功保存才写新版，原有事项和设置保留。未知版本会保留原文件并明确报错。

**v1.5.0及更早 Windows 程序、已发布 Mac 0.1.0-alpha.1 不能读取 Version 3。回退时先恢复升级前单独保存的整个 Data，再运行旧程序。** 滚动更新的 `todos.json.bak` 不能代替升级前备份，不让新旧程序交替写同一目录。

## 平台与验证边界

Windows 目标为 Windows 10 / 11、.NET Framework 4.7.2 或更新版本。周期检查由运行中的程序执行，退出或关机时不生成；重开后处理遗漏。它不是后台闹钟，也不包含手机端、跨设备同步、富文本、附件或子任务。

本地自动化覆盖周期计算、月底与闰年、去重、删除后不重生、失败事务、规则管理、编辑展开及旧数据迁移；干净源码打包会重新构建并运行全部登记测试，实际结果以 `PACKAGE-REPORT.txt` 为准。README 新图使用合成事项和真实 WPF 控件渲染，AI 效果图不作为实机结果。桌面层、真实鼠标输入和不同显示环境仍需实机检查。

Mac 本轮同步共享数据保存与构建兼容，未接入周期生成及管理界面，也没有发布新的 Mac 程序。原 alpha.1 附件保持原样，不能读取新版数据；Mac 真机验收仍单独进行。

本版未进行发布者数字签名。请核对来源与摘要并保持系统防护开启；SHA256仅用于核对文件一致性。
