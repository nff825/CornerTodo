# CornerTodo v1.2.0

本次新增可由用户自行开启的登录自启动，默认关闭，继续保持 WPF 免安装便携运行。

- 从「⋯」菜单自行开启「开机自启（登录后）」；首次运行和升级不会自动开启。
- 只在当前 Windows 用户启动文件夹登记唯一受管快捷方式 `CornerTodo-LoginStartup.lnk`，关闭仅删除本工具管理的项。
- 菜单勾选表示快捷方式已登记，不在 JSON 保存跨机器启用开关；Windows 外部禁用后仍需用户在系统设置中重新启用，程序不会在后台绕过禁用。
- 新增「更新自启位置为当前程序」，移动目录后可主动修复登记，不在后台自动覆盖旧目标。
- 从菜单退出只结束本次运行；下次登录按登记启动。自动重复启动会静默退出，不展开或重置已经运行的面板。

继续支持事项管理、截止时间驱动的自动扩大、外观设置与面板拖动和折叠。面向 Windows 10 / 11，需要 .NET Framework 4.7.2 或更新版本；本地保存、不联网。

## 下载与升级

- 使用程序：下载 `CornerTodo-v1.2.0-windows-portable.zip`，完整解压后运行 `CornerTodo.exe`。
- 查看或构建源码：使用仓库代码，或下载 `CornerTodo-v1.2.0-source.zip`。
- 校验文件：`SHA256SUMS.txt`。

升级前先从菜单退出旧版并备份程序旁的 `Data` 文件夹，替换程序时保留原数据目录。

在原目录升级并保持程序路径时，已有自启登记保留。移动目录后，请手动打开新位置的程序，再选择「更新自启位置为当前程序」。删除软件前请先关闭登录自启动。完整说明见 [登录自启动说明](STARTUP.md)。

## 验证范围与已知限制

发布流程使用干净源码副本构建，运行五组测试并校验压缩包哈希；不打包个人 Data、日志或本机登录登记。登录测试使用隔离环境，不会擅自注销或重启电脑。真实登录、Windows 外部禁用和不同桌面环境仍需主动进行回归。

此版本未进行发布者数字签名，部分 Windows 安全策略可能提示或阻止运行。请核对来源与文件校验值，并保持系统防护开启。不同 Windows 版本、显示缩放和多显示器组合尚未全部验证。文件校验值只用于核对文件一致性，不保证兼容性或安全。
