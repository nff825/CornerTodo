# CornerTodo v1.1.0

本次新增外观设置，可按壁纸调整待办面板的颜色与背景透明度。

- 从「⋯ → 外观设置」调整背景透明度、背景色及主要／次要文字颜色。
- 透明度范围为 0%～100%；背景透明时文字保持清晰，不跟着变淡。
- 提供浅色、深色和恢复原版预设，支持色值输入与系统颜色选择器。
- 实时预览；点击保存后持久化，取消或关闭窗口恢复原设置，保存失败不会覆盖已提交设置。
- 全透明时菜单按钮仍可辨认，并提供「恢复清晰浅色」快捷入口。
- 旧版待办数据兼容，事项、截止时间和常态面板尺寸保留。

继续支持创建、编辑、删除、完成与恢复事项，截止时间驱动的自动扩大，以及面板拖动和折叠。

面向 Windows 10 / 11，需要 .NET Framework 4.7.2 或更新版本。免安装、本地保存、不联网、不设置自启动。

## 下载

- 使用程序：下载 `CornerTodo-v1.1.0-windows-portable.zip`，完整解压后运行 `CornerTodo.exe`。
- 查看或构建源码：使用仓库代码，或下载 `CornerTodo-v1.1.0-source.zip`。
- 校验文件：`SHA256SUMS.txt`。

升级前先从菜单退出旧版并备份程序旁的 `Data` 文件夹，再替换程序文件，保留原数据目录。外观设置也保存在这个目录中。
