# CornerTodo v1.2.1

本次整理工程结构，并改善窗口丢失后的恢复与退出清理，继续保持 WPF 免安装便携运行。

- 统一 Visual Studio／MSBuild 与 PowerShell 构建入口，共用显式源码、引用、测试和公开文件清单。
- 26 个生产源码文件按职责归入 `src/App`、`src/Tasks`、`src/UI`、`src/Windows`，工程与构建入口保留在根目录；仍使用单个应用程序集和 `CornerTodo` 命名空间。
- 拆分任务操作服务、面板显示与交互、单实例通信和应用启动生命周期，便于后续维护与验证。
- 修复延迟恢复过早读取旧快照的问题：编辑或模态操作结束后，再以最新已提交状态重建面板。
- 改善退出时的恢复计时、排队挂接与回调清理，避免旧窗口事件或过期工作再次影响面板。

现有事项管理、截止时间驱动的自动扩大、外观设置、拖动和折叠功能保持兼容，JSON 数据格式不变。登录自启动仍默认关闭，由用户自行开启；首次运行和升级不会自动登记。面向 Windows 10 / 11，需要 .NET Framework 4.7.2 或更新版本；本地保存、不联网。

## 下载与升级

- 使用程序：下载 `CornerTodo-v1.2.1-windows-portable.zip`，完整解压后运行 `CornerTodo.exe`。
- 查看或构建源码：使用仓库代码，或下载 `CornerTodo-v1.2.1-source.zip`。
- 校验文件：`SHA256SUMS.txt`。

升级前先从菜单退出旧版并备份程序旁的 `Data` 文件夹，替换程序时保留原数据目录。

在原目录升级并保持程序路径时，已有自启登记保留。移动目录后，请手动打开新位置的程序，再选择「更新自启位置为当前程序」。删除软件前请先关闭登录自启动。完整说明见 [登录自启动说明](STARTUP.md)。
