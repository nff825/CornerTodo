# CornerTodo v1.5.0｜无截止日期与简约滚动条

有些事项只是想先记下来，不需要勉强填一个截止日期。本次支持「未设截止」，并改善主面板滚动条的外观。

- **截止日期可选**：取消「设置截止日期」后，日期和具体时刻控件收起，可以直接保存；备注、优先级、完成与恢复照常使用。
- **无日期不产生紧迫度**：显示「未设截止」，隐藏时间条，不计入临期和逾期，不推动面板扩大；仍计入未完成总数和胶囊数量。
- **排序明确**：截止时间优先时，有日期事项在前、无日期在后。优先级优先时，先分高／中／低，同级内有日期在前；无日期按创建时间稳定排列。
- **进度起点准确**：为无日期事项补设截止，从本次保存开始计算；取消日期后停止贡献紧迫度。单纯修改文字、备注或优先级不重置已有截止进度。
- **简约滚动条**：主面板使用透明轨道和圆角细滑块，悬停／拖动加深，操作区宽度保持不变，配合浅色、深色与自定义配色。

小时／分钟点选、默认关闭的贴边收起和登录自启、外观设置、本地保存与备份继续保留。时间条表示时间已用比例，不表示任务完成度；无日期和已完成事项不显示时间条。

## 下载与升级

- 普通 Windows 用户：下载 `CornerTodo-v1.5.0-windows-portable.zip`，完整解压后运行 `CornerTodo.exe`。
- 查看／构建源码：下载 `CornerTodo-v1.5.0-source.zip`，含 Windows 工程与同步兼容的 Mac 开发分支。
- 校验文件：`SHA256SUMS.txt`。

升级前先从菜单退出旧程序，单独复制并保留整个 `Data` 文件夹作为升级前备份。更新程序文件时保留原 `Data`；每份便携程序默认读取自己旁边的数据，换目录运行不会自动带入旧事项。

**数据格式升级为 Version 2。** 原 Version 1 的事项、日期、备注、优先级及设置会在载入后进行内存迁移，首次成功保存才写入新版格式。新建事项默认保留设置截止日期的习惯，用户可取消。

**v1.4.0 及更早 Windows 程序、已发布 Mac 0.1.0-alpha.1 不能读取 Version 2。回退时必须先恢复升级前整个 Data 备份，再运行旧程序。** `todos.json.bak` 会随保存滚动更新，不能替代升级前另存的备份。不要让新旧版本交替写入同一目录。

保持原程序路径时，已有自启登记继续保留；移动目录后需要手动更新自启位置，见 [登录自启动说明](STARTUP.md)。

## 平台与验证边界

Windows 目标为 Windows 10 / 11、.NET Framework 4.7.2 或更新版本。本地自动化验证覆盖数据迁移、无日期往返与排序、进度／紧迫度、编辑草稿、滚动样式以及现有功能；干净源码打包流程会重新构建并运行全部登记的功能测试，具体结果以随包 `PACKAGE-REPORT.txt` 为准。

实际桌面层、不同显示缩放与多显示器、真实登录等组合仍需实机确认。README 中的新界面图片来自实际 WPF 控件渲染，使用合成事项；AI 设计图不作为实机结果。

Mac 开发分支已同步无日期和新版数据的兼容接线，但本次没有发布新 Mac 程序，也不代表 Mac 真机验收通过。原 Mac 内测附件及标签继续保留，请勿让原 0.1.0-alpha.1 打开 Version 2 数据。

当前没有周期任务、提醒通知、跨设备同步、附件、富文本或子任务。
