# CornerTodo v1.7.0｜视觉统一与可选悬浮置顶

本次改善操作区和滚动条的协调性，并增加可选的悬浮显示。默认仍在桌面显示；需要在其他软件上方查看待办时，再由用户开启。

- **按需悬浮**：从「⋯ → 显示方式」切换「仅在桌面显示」或「悬浮在其他窗口上方」，选择会保存在本地。面板和贴边胶囊在悬浮模式下可显示在普通办公窗口上方。
- **扩大开关独立**：桌面与悬浮分别保存「随截止时间扩大」偏好。桌面保留原设置；悬浮默认不自动扩大，先使用常态尺寸，也可按需开启。
- **操作区统一**：顶部收起／更多与底部「添加待办」采用同系底色、圆角、描边及悬停／按下反馈，配合浅色、深色及自定义外观。面板高度透明时仍保留可辨认的入口。
- **细滚动条**：保留透明轨道、无上下箭头与圆角细滑块，颜色与主题一致，拖动区域不随视觉宽度一起缩小。
- **保留已有功能**：重复任务、无截止日期、备注、优先级与排序、时间细条、可选贴边收起及登录自启动继续保留。

悬浮模式面向浏览器、文档编辑器等普通窗口，不承诺覆盖独占全屏、其他置顶窗口或系统安全界面。它与到期通知是不同功能；本版没有新增弹窗或声音提醒。

## 下载与升级

- 普通 Windows 用户：`CornerTodo-v1.7.0-windows-portable.zip`，完整解压后运行 `CornerTodo.exe`。
- 源码：`CornerTodo-v1.7.0-source.zip`，包含 Windows 工程及共享数据兼容的 Mac 开发工程。
- 摘要：`SHA256SUMS.txt`。

升级前退出旧程序，单独复制并保留整个 `Data` 文件夹，再替换程序文件、保留原数据。换目录运行时需带上原 `Data`；固定日常目录可保留登录自启动登记，移动目录后需手动更新自启位置。

**数据格式继续为 Version 3。** 本版新增可选显示设置，旧文件缺少时默认使用桌面模式，悬浮自动扩大关闭。Version 1／2 仍在载入后内存迁移，首次成功保存才写新版。

**v1.6.0 能读取本版任务数据，但再次保存会丢失新增的悬浮显示偏好。v1.5.0 及更早 Windows 程序、已发布 Mac 0.1.0-alpha.1 不能读取 Version 3。** 回退请使用升级前单独保存的整个 `Data` 备份，勿让新旧版本交替写同一目录；滚动更新的 `todos.json.bak` 不能代替升级前备份。

## 验证范围与平台

Windows 目标为 Windows 10 / 11、.NET Framework 4.7.2 或更新版本。本地检查覆盖显示设置、旧字段默认、保存事务与回滚、显示模式切换、挂载清理及主题和滚动条呈现，具体结果以随包 `PACKAGE-REPORT.txt` 和验证日志为准。

README 的新增界面图片来自真实 WPF 控件的离屏渲染，使用合成事项；它们展示配色与布局，不证明原生窗口已置顶。浏览器／办公软件上的实际层级、Win+D、Explorer 重启、真实鼠标输入及多屏／显示缩放仍需实机检查。

Mac 本轮仅保持共享数据和构建兼容，保存时保留新的 Windows 显示偏好，未提供 Mac 悬浮模式界面或周期生成与管理。本次没有发布新 Mac 程序，原 alpha.1 附件和标签保持原样，不能读取新版数据。

本版未进行发布者数字签名。请核对来源与摘要并保持系统防护开启；SHA256 用于核对文件一致性。
