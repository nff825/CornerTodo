# CornerTodo v1.0.0

Windows 桌面右上角的半透明待办清单，随着截止时间临近逐渐扩大，让紧急事项更醒目。

支持创建、编辑、删除、完成和恢复事项；独立设置截止日期与具体时刻；完成事项保留并划线。所有紧急和逾期事项均放大字号，顶部汇总数量。面板可拖动、折叠，并可关闭自动扩大。

面向 Windows 10 / 11，需要 .NET Framework 4.7.2 或更新版本。免安装、本地保存、不联网、不设置自启动。

## 下载

- 使用程序：下载 `CornerTodo-v1.0.0-windows-portable.zip`，完整解压后运行 `CornerTodo.exe`。
- 查看或构建源码：使用仓库代码，或下载 `CornerTodo-v1.0.0-source.zip`。
- 校验文件：`SHA256SUMS.txt`。

首次运行后会在程序旁生成个人 `Data` 文件夹。升级前先退出旧版并备份该目录，替换程序时保留数据。
