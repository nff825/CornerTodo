# CornerTodo v1.3.0

本次增加事项备注、时间进度细条和优先级排序，让桌面上的事项保持简洁，同时保留执行细节。

- **事项备注**：支持可选多行纯文字。列表仅显示备注图标；点击进入编辑窗口查看或修改，完成后仍保留。新建时默认收起备注，已有备注时自动展开。
- **简短优先级**：高／中／低，默认中，列表使用小标签。
- **两种排序**：默认截止时间优先，也可选择优先级优先。优先级模式按高 → 中 → 低排列，同级按截止时间排列，选择会在本机保存。
- **时间进度细条**：约 3 像素，按每条事项自己的完整期限线性推进。鼠标悬停查看“时间已用”比例，到期满格，逾期保持满格并显示逾期时长；已完成事项隐藏时间条。
- **时间规则保持一致**：只修改文字、备注、优先级或排序不会重置进度；修改有效截止时间后重新计算。时间条表示经过的时间，不表示工作完成度。
- **编辑与实时更新**：保存失败时保留编辑窗口中的输入，支持直接重试；鼠标停在面板上时，时间条和行内截止提示继续更新。

优先级优先不会额外强制逾期置顶，因此较晚截止的高优先级事项可能排在较早截止的中优先级事项前面。临期、逾期文字提示与原有面板自动扩大继续生效；面板扩大使用原来的临期规则，与完整周期时间条分别计算。

原有外观、拖动、折叠及本地备份继续保留。登录自启动仍默认关闭，由用户自行开启。应用面向 Windows 10 / 11，需要 .NET Framework 4.7.2 或更新版本；本地保存、不联网。当前不包含手机端、跨设备同步、提醒通知、附件、富文本或子任务。

## 下载与升级

- 使用程序：下载 `CornerTodo-v1.3.0-windows-portable.zip`，完整解压后运行 `CornerTodo.exe`。
- 查看或构建源码：使用仓库代码，或下载 `CornerTodo-v1.3.0-source.zip`。
- 校验文件：`SHA256SUMS.txt`。

升级前先从菜单退出旧版并备份程序旁的整个 `Data` 文件夹，替换程序时保留原数据目录。长期使用建议固定同一个运行位置；每份便携程序默认读取自己旁边的 `Data`，切换到新的版本目录不会自动带入旧事项。v1.2.1 旧事项缺少新字段时，自动按空备注、中优先级和截止时间优先读取。

旧版程序写回新版数据时，会丢弃其不认识的备注、优先级和排序字段。如需回退，请使用升级前的 `Data` 备份，避免新旧版本交替写入同一份数据。

在原目录升级并保持程序路径时，已有自启登记保留。移动目录后，请手动打开新位置的程序，再选择“更新自启位置为当前程序”。删除软件前请先关闭登录自启动。完整说明见 [登录自启动说明](STARTUP.md)。

## 验证范围与已知限制

本地验证已通过共享清单登记的全部 11 组功能测试，以及隔离工程与打包检查。覆盖旧数据兼容、备注和优先级保存、两种排序、截止前后时间进度、保存失败保留输入与重试，以及小窗口布局。实际 WPF 控件在 150% 缩放下渲染为图片并检查；本版尚待用户在真实桌面上试用。

自动测试使用隔离数据、未显示的窗口、假窗口或假桌面适配器等方式。发布流程从干净源码副本构建，不打包个人 `Data`、日志或本机登录登记。不同 Windows 环境、真实登录、Windows 外部禁用及 Explorer 重启仍需实机回归。

此版本未进行发布者数字签名，部分 Windows 安全策略可能提示或阻止运行。请核对来源与文件校验值，并保持系统防护开启。不同 Windows 版本、显示缩放和多显示器组合尚未全部验证。文件校验值只用于核对文件一致性，不保证兼容性或安全。
