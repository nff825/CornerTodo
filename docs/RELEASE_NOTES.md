# CornerTodo v1.9.0｜截止日历

Windows 面板的「⋯」菜单新增「截止日历…」，打开独立窗口查看每月的截止事项。

- 使用左右箭头翻月，点击「今天」回到当前日期。事项按本地截止日期归入月格，每格最多显示两条标题，其余条数用 `+N` 标出。
- 点选日期可查看该日事项，在详情中直接编辑或标记完成。勾选「显示已完成」可查看或恢复已完成的事项。
- 可单独查看逾期和未设截止事项。已生成的重复期次同样显示，已有到期提醒按原计划运行。

v1.8.0 的提醒功能及其他历史变更见仓库中的 `CHANGELOG.md`。本次为 Windows 功能更新。Mac 实验性内测版本仍为 0.2.0-alpha.1（构建 0.2.1）。

## 下载与升级

Windows 便携包为 `CornerTodo-v1.9.0-windows-portable.zip`，完整解压后运行 `CornerTodo.exe`。源码包为 `CornerTodo-v1.9.0-source.zip`，校验文件为 `SHA256SUMS.txt`。

升级前从菜单退出旧程序，单独复制并保留整个 `Data` 文件夹，再替换程序文件、保留原数据。换目录运行时需带上原 `Data`；移动目录后需手动更新已登记的自启位置。

**本版沿用 v1.8.0 的 Version 4 数据格式。** 旧 Version 1／2／3 载入时在内存迁移，首次成功保存后写入 Version 4。旧事项默认关闭提醒，原有任务、周期与显示偏好保留。

**v1.7.0 及更早的 Windows 程序、已发布 Mac 0.1.0-alpha.1 无法读取 Version 4。回退到这些版本前，请先恢复升级前另存的整个 `Data` 备份。** 请单独保留这份备份，日常的 `todos.json.bak` 会滚动更新。

## 系统要求与验证

系统目标为 Windows 10／11 和 .NET Framework 4.7.2 或更新版本。实际桌面上的窗口焦点、多显示器和缩放环境仍需试用。自动检查结果以本次打包的 `PACKAGE-REPORT.txt` 为准。
