# CornerTodo v1.11.0｜四象限

Windows 面板新增「⋯ → 四象限…」，在独立窗口中按重要性和截止紧迫度查看事项，可直接添加、编辑、完成或恢复待办。

- 添加或编辑时勾选「标为重要」，重要标记与高／中／低优先级分别设置。新事项与迁移的旧事项默认未勾选。
- 逾期或距截止不超过紧急范围的事项归为紧急，默认 24 小时，可选 6 小时、24 小时、3 天或 7 天。未设截止归为不紧急；主面板继续按原有 6 小时规则放大临期文字。
- 每格按优先级及截止时间排序。默认隐藏已完成，显示时以完成时刻计算紧迫度，恢复后按当前时刻重新归类。
- 已生成的重复期次会显示，未来期次待生成后加入。后续期次继承规则的重要标记，修改规则保留已生成事项的标记。
- 四象限跟随外观字号与实时预览，悬浮状态与主面板同步。

文字大小调节、截止日历和到期提醒等历史变更见仓库中的 `CHANGELOG.md`。Mac 已分发的实验性内测版仍为 0.2.0-alpha.1（构建 0.2.1），使用 Version 4 数据。本次共享开发源码同步 Version 5 数据兼容，尚无新 Mac 程序或四象限界面。

## 下载与升级

Windows 便携包为 `CornerTodo-v1.11.0-windows-portable.zip`，完整解压后运行 `CornerTodo.exe`。源码包为 `CornerTodo-v1.11.0-source.zip`，校验文件为 `SHA256SUMS.txt`。

升级前从菜单退出旧程序，单独复制并保留整个 `Data` 文件夹，再替换程序文件、保留原数据。换目录运行时需带上原 `Data`；移动目录后需手动更新已登记的自启位置。

**本版升级为 Version 5 数据格式。** 正常载入 Version 1～4 时只在内存迁移，首次成功保存后写入 Version 5。旧任务与规则默认未标为重要，紧急范围默认 24 小时；原有任务、提醒、周期与显示偏好继续保留。

**Windows v1.10.0 及更早版本和已分发的 Mac 内测程序均无法读取 Version 5。回退前请先恢复升级前另存的整个 `Data` 备份，再运行旧程序。** 请单独保留这份备份，日常的 `todos.json.bak` 会滚动更新。

## 系统要求与验证

系统目标为 Windows 10／11 和 .NET Framework 4.7.2 或更新版本。四象限尚待原生桌面实测，窗口焦点、多显示器和缩放环境仍需试用。自动检查结果以本次打包的 `PACKAGE-REPORT.txt` 为准。

便携程序未进行发布者数字签名。可用 SHA256 核对文件一致性。许可证为 MIT，见 `LICENSE`。
