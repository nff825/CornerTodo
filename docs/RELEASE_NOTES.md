# CornerTodo v1.10.0｜文字大小调节

Windows 外观设置新增「文字大小」，可在 90%～150% 之间调节，默认 100%。从「⋯ → 外观设置」打开，拖动滑块实时预览，点击「保存」后保留。取消或关闭设置窗口可恢复已保存的外观。

- 主面板的事项正文、日期与已完成文字按比例显示，临期和逾期事项保留相对字号层级。
- 截止日历中的事项文字与日期也跟随设置与实时预览，文字换行和滚动区域随字号适配。
- 点击「恢复100%」可单独还原字号。切换浅色、深色或原版颜色预设保留当前字号；窗口底部的「恢复默认」将颜色、透明度和字号一起恢复为清晰浅色与 100%，保存后生效。

v1.9.0 的截止日历与 v1.8.0 的到期提醒继续提供，历史变更见仓库中的 `CHANGELOG.md`。本次为 Windows 功能更新。Mac 实验性内测版本仍为 0.2.0-alpha.1（构建 0.2.1）。

## 下载与升级

Windows 便携包为 `CornerTodo-v1.10.0-windows-portable.zip`，完整解压后运行 `CornerTodo.exe`。源码包为 `CornerTodo-v1.10.0-source.zip`，校验文件为 `SHA256SUMS.txt`。

升级前从菜单退出旧程序，单独复制并保留整个 `Data` 文件夹，再替换程序文件、保留原数据。换目录运行时需带上原 `Data`；移动目录后需手动更新已登记的自启位置。

**本版沿用 v1.8.0／v1.9.0 的 Version 4 数据格式。** 旧数据缺少文字大小设置时按 100% 显示。旧 Version 1／2／3 载入时在内存迁移，首次成功保存后写入 Version 4。旧事项默认关闭提醒，原有任务、周期与显示偏好保留。

**v1.7.0 及更早的 Windows 程序、已发布 Mac 0.1.0-alpha.1 无法读取 Version 4。回退到这些版本前，请先恢复升级前另存的整个 `Data` 备份。** 请单独保留这份备份，日常的 `todos.json.bak` 会滚动更新。

## 系统要求与验证

系统目标为 Windows 10／11 和 .NET Framework 4.7.2 或更新版本。字号功能尚待原生桌面实测，窗口焦点、多显示器和缩放环境仍需试用。自动检查结果以本次打包的 `PACKAGE-REPORT.txt` 为准。

便携程序未进行发布者数字签名。可用 SHA256 核对文件一致性。许可证为 MIT，见 `LICENSE`。
