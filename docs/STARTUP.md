# 登录自启动说明

CornerTodo 从 v1.2.0 起提供「开机自启（登录后）」，默认关闭。首次运行和升级不会自动开启。它在当前 Windows 用户登录后启动程序，其他用户的登录项不受影响。

## 开启与关闭

1. 先把便携版完整解压到准备长期使用的可写目录，手动打开 `CornerTodo.exe`。
2. 在面板「⋯」菜单点击「开机自启（登录后）」。登记成功后菜单会勾选；当前用户下次登录时会启动该位置的程序。
3. 需要取消时，再点击这个菜单项。关闭只删除 CornerTodo 自己管理的快捷方式，不删除其他软件或用户创建的登录项。

开启时，工具在当前用户的 Windows 启动文件夹创建唯一受管快捷方式 **`CornerTodo-LoginStartup.lnk`**。可以按 `Win + R`，输入 `shell:startup` 查看这个文件夹。快捷方式记录程序所在的位置；它不保存在便携版的 `Data` 目录中。

## 菜单状态与 Windows 的禁用状态

菜单勾选表示**本工具管理的快捷方式已登记**。这个状态每次根据真实登记检查，不在 `todos.json` 中保存一个跨机器使用的启用开关。复制待办数据到另一台电脑不会替那台电脑开启登录自启动。

如果你曾在 Windows 的启动应用设置或任务管理器中禁用了 CornerTodo，快捷方式可能仍在，菜单也可能仍显示勾选，但 Windows 会阻止自动运行。需要你在系统的启动应用列表中自行重新启用。

CornerTodo 不会在后台覆盖、重建快捷方式来绕过这种禁用，也不会擅自重新启用 Windows 中已禁用的启动项。菜单里的「更新自启位置为当前程序」用于你主动迁移目录后的修复，不代表系统已允许启动。

## 退出与重复启动

- 「退出待办」只结束当前这次运行，不关闭已经开启的登录自启动。若要以后不再自动运行，请先关闭「开机自启（登录后）」。
- 下次登录按已登记的位置启动。自动启动发生时，如果同一份待办已经在运行，会静默结束这次重复启动，保留已有面板的位置与收起状态。
- 手动双击程序仍按普通启动处理，可恢复已有面板；自动启动不会借此展开或重置面板。

## 升级、移动与删除

| 操作 | 需要做什么 |
| --- | --- |
| 第一次使用或从未开启过自启 | 保持关闭；需要时再由你从菜单开启 |
| 在原目录升级 | 从菜单退出旧版、备份 `Data`，替换程序文件并保留程序路径；已有自启登记继续保留 |
| 移到新目录 | 保留并迁移 `Data`，手动打开新位置的程序，再点击「更新自启位置为当前程序」；程序不会在后台自动覆盖旧目标 |
| 删除软件 | 先通过菜单关闭登录自启动，再退出并删除程序文件；按需要保留个人 `Data` 备份 |

如果旧目录已删除，先手动运行新位置程序，再主动更新自启位置；不要仅复制 `Data` 后期待登录登记自动跟随。若 Windows 之前禁用过启动项，更新位置后仍需在系统中检查并重新启用。

## 手动检查

可在你方便时按下面的顺序验证：

1. 手动打开程序，确认初始未登记时菜单不勾选。
2. 自行开启，检查当前用户启动文件夹中出现 `CornerTodo-LoginStartup.lnk`。
3. 自行关闭，确认该受管文件移除，其他登录项保持原样。
4. 若需要真实登录验证，再次开启，保存好其他工作后，由你自己选择何时注销并重新登录。
5. 登录后检查面板状态；测试完毕可按使用习惯保留或关闭自启。

构建中的登录自启动测试使用隔离测试环境；不会擅自注销、重启电脑，或替你开启真实登录自启动。真实登录、Windows 外部禁用及不同桌面环境的回归仍需用户主动操作。
